# Holo Card HTML

브라우저에서 카드를 회전하고 홀로그램 효과를 살펴볼 수 있는 HTML 카드입니다.

## 사용하기

저장소의 `index.html`을 브라우저에서 열면 됩니다. 카드를 드래그해 회전하고, 화면의 버튼과 슬라이더로 뒤집기와 효과를 조절할 수 있습니다.
